#Is It Really Safer to Fly Private?

People often assume that flying on a private jet is safer than flying on a commercial airplane. In this project I want to check if that's actually true, using real U.S. aviation accident data from 2000 to 2024.

Instead of just counting accidents, I compare accident rates (accidents per
flight hours) for airlines, charter flights and private flying.

## Data
- NTSB aviation accident database
- FAA General Aviation and Part 135 Activity Survey
- BTS National Transportation Statistics
